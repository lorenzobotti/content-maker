# lyric video maker

make vertical lyric videos in your browser. intended for music artists promoting their music on tiktok and ig reels

```sh
npm install
npm run dev
```

1. **setup**: add a background, the song and the lyrics (paste, `.txt` or `.lrc`)
2. **sync**: tap `space` on each word
3. **style**: pick an animation, font and colors
4. **export**: record to mp4 (webm on firefox)
